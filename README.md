# ControlAlmacenApp (App Tablet)

Aplicación Android (Tablet) para gestionar inventario de un almacén (sin servidor), con base de datos local (Room/SQLite).

## Tecnologías
- Android Studio
- Java
- Room (SQLite)
- Arquitectura: MVC
- Control de versiones: GitHub
